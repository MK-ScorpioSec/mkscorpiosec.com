Case Study — PentAGI AI Agent Analysis

When the pentesting tool is the threat vector

PentAGI is an autonomous AI-powered penetration testing agent. I analyzed it from the inside — static codebase review, then a full dynamic sandbox with custom instrumentation built from my own stack. No real API keys. No internet access. Just the agent and a controlled environment.

The findings were not about PentAGI being malicious. The finding was structural: any AI agent with shell execution generates LLM traffic indistinguishable from an active attacker.
